# alert maker

## Explanation

alert maker is a macOS app made on an Intel Mac. It wasn't super simple to make but it was still kinda simple (and by kinda simple i mean not simple at all) since i had to code it in Swift.
I don't even know if i'll update it but if i do it's probably not gonna be much.

## Requirements

Device: **Any device running macOS**
OS: **macOS** (i think that was obvious tho)
CPU: **Any** (Will **NOT** work on **Apple Silicon** once **macOS 28** comes out.)

## How to install

1. **Download [alert-maker-installer.dmg](https://github.com/Bagelman47/alert-maker/releases/download/v1.0.0/alert-maker-installer.dmg)**
2. **Run alert-maker-installer.dmg**
3. **Drag alert-maker into your Applications folder and open the app!**
